# Icon sizing reference

All brand icons are clean, vector SVGs with a 24 × 24 viewBox. They scale without pixelation; use CSS dimensions rather than maintaining separate raster files.

| Context | Suggested rendered size |
|---|---:|
| Dense mobile navigation | 20 px |
| Mobile action / list | 24 px |
| Desktop navigation | 20–24 px |
| Dashboard card | 24–28 px |
| Feature tile | 32–40 px |
| Large empty state / illustration | 48–64 px |
| Marketing / high-density export | 96–512 px |

Pre-rendered transparent PNG exports are included at 16, 20, 24, 32, 40, 48, 64, 96, 128, 192, 256, and 512 px in `png/<size>/`. The SVG master remains the source of truth.
